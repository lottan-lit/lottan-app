# LOTTAN para Android — 0.2.3

Site: https://lottan-lit.github.io/lottan-app/

- Reserva estável das barras do sistema, independente da visibilidade; teclado continua ajustando a área útil.
- Modo imersivo preservado, com revelação por gesto.

- Mesmo pacote, certificado e dados da 0.2.2: instalar como atualização.
